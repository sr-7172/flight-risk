# STANDING RULES (Part 0 — binding for every round)

These bind every agent in every round. Round files incorporate them by reference; a round may add rules but never weaken these.

## Inference

1. **No hand-rolled inference.** Clustered SEs and wild bootstraps go through `pyfixest` (or the `wildboottest` package). If they fail to install or their API differs from expectations: STOP, record the error in STATUS.md, mark the task BLOCKED, move on. Never reimplement CGM or a bootstrap by hand.
2. **Rank check before every fit.** Assert full column rank, or use pyfixest's collinearity handling and LOG what was dropped. A rank failure is a finding to report, not an obstacle to silence.
3. **Few-cluster regressors.** Any variable identified off a small number of clusters (e.g., year-level regressors with ~15–25 years) gets inference in that dimension — wild cluster bootstrap over the few dimension — never fine-only clustering.

## Sanity gates

4. **Gates are binding code**, implemented inside the estimation script. A gate failure → write the diagnostic, set the flag, mark BLOCKED in STATUS.md, continue to the next task. NEVER relax a gate, widen a bound, exempt a file, or choose the estimator that "works". If two methods disagree wildly, both are suspect; the deliverable is the DEGENERATE-INFERENCE flag plus diagnostics.

   Default gates every regression output must pass (rounds may tighten, never loosen):
   - **G1** — no empty cells in coef/se/pval; pval ∈ [0, 1].
   - **G2** — no |coef| > 100 on log/share outcomes (rank-deficiency signature).
   - **G3** — no p-value of exactly 0.0; no identical p-value repeated across a family of coefficients.
   - **G4** — SE scale sane: no starred coefficient with |SE/coef| > 20; clustered p-values not 3+ orders of magnitude below the robust p-values for the same coefficient.
   - **G5** — shares/rates/survival/precision ∈ [0, 1]; every multiple-testing family reports its full cell count, significant and not.

5. **Numbers are written only by code.** No one types a result number into a log, report, or commit message. FINAL_RUN_LOG.md is generated by `code/build_run_log.py` only; human-readable/MIN_SCRIPTS.md by `code/sync_min_scripts.py` only. STATUS.md lines describe state, never coefficients. The one sanctioned exception: ROUND_NN_FINDINGS.md and human-readable/PROJECT_STATE.md may cite numbers that are transcribed directly from a CSV in the round folder with an inline trace `(file.csv, row/spec)` — never from prose, never untraced.
6. **Nulls and reversals are reportable results.** A null interaction or a failed placebo is a deliverable, not a problem to fix.
7. **Review loop.** Overseer verdicts gate acceptance. Address Required actions literally and in order. After 3 implement→review cycles on one task: BLOCKED-NEEDS-HUMAN with a neutral summary of the disagreement.
8. **Git.** Commit after each task passes review (`FIX-NN: <one line>`). Never push. Never destructive commands (`rm -rf`, `git reset --hard`, `git clean`). Never touch `data/raw/`.

## Round folders & findings

Each round lives in its own folder `rounds/round-NN-<slug>/` containing the work order (`ROUND_NN.md`), ALL of the round's outputs (CSVs, figures, TeX; `figures/`/`tables/` subfolders allowed), and `ROUND_NN_FINDINGS.md` written at round close per the contract in rounds/ROUND_TEMPLATE.md: plain-language narrative for a coauthor with zero context (toddler-level method explanations), traced numbers only, the complete list of scripts created/edited this round (reconciled against git), and a **Suggested next steps** section. That section replaces the old auto-drafted next-round file: /plan-round seeds from the latest findings (plus any human edits to it). The validator and run-log builder scan `rounds/round-*/` directory-wide; `rounds/*/legacy_quarantine/` holds superseded artifacts.

## OpenSky Trino discipline (binds every agent)

16. **OPENSKY_TRINO_RULES.md (T1–T9) is part of these standing rules.** All Trino access goes through `code/opensky_query.py`, whose partition-column, chunk-size, bound, and serial-execution guards are never edited or bypassed; unattended runs never query live; `code/98_check_trino_usage.py` must exit 0 at every round close. A task that cannot be completed within T1–T9 is BLOCKED, not worked around — OpenSky bans violators and a ban ends the project's data access.

## Spec CSV schema

Every regression output CSV carries: `spec`, `outcome`, `variable`, `coef`, `se`, `pval`, `n_obs`, `cluster_level`, `stars_source` (which p-value column stars were derived from) — plus any SE-menu columns a task specifies (e.g., `se_hc1`, `se_cl1`, `se_cl2`, `se_wcb`, `pval_wcb`).

## Direction integrity (binds the director)

9. Every commissioned task is labeled **EXPLORE** or **CONFIRM**. CONFIRM tasks carry an ex-ante rationale written before results exist. EXPLORE families are reported in full — every cell, nulls included — and nothing found in exploration is promoted to a headline claim without a written, result-independent selection rationale plus a multiple-testing note.
10. **No re-specification aimed at recovering significance.** A robust null or failed placebo closes a thread with a post-mortem in RESEARCH_LOG.md. Variations exist to test fragility, and all of them get reported.
11. Changes to the research question, sample definition, or headline outcomes after results are known are DECISION-PENDING for the human, recorded in DECISIONS.md; the run continues on the conservative default.
11b. **Round close deliverables.** The director closes every round by writing ROUND_NN_FINDINGS.md (contract above) and refreshing human-readable/PROJECT_STATE.md in undergrad-RA register — plain language, jargon glossed, no untraced numbers. A new round file is drafted only when explicitly commissioned (/plan-round, or the auto-chaining clause of /run-analysis), and then FROM the latest findings' Suggested next steps.

## Method discipline (seminar-first)

12. **Simple methods are the default.** The standing toolkit is: sample means and raw-data plots, OLS/WLS with fixed effects, canonical difference-in-differences with event-study figures, and 2SLS from PROJECT.md's identification menu. Estimators outside this menu require an explicit commission in the round file with a written design reason, and the simple benchmark always runs first and is reported alongside. Divergence between simple and fancy is a deliverable, not a nuisance. Every headline table must be explainable in two sentences to a seminar audience.

## Writing integrity (binds the author)

13. **Numbers enter the paper and slides only through generated artifacts.** Tables and figures in `paper/` and `slides/` are built by code (`code/spec_to_tex.py` or task-specific scripts) reading `rounds/round-*/` CSVs, and included via `\input`/`\includegraphics`. No result number is ever typed into a `.tex` file by hand.
14. **Citations are verified or flagged.** A reference appears in `references.bib` only if the author agent has actually retrieved and read at least its abstract (web tools) — otherwise it is listed in docs/LIT_NOTES.md under UNVERIFIED with a note to check before circulation. Fabricated or from-memory citations are the writing equivalent of a hand-typed coefficient.
15. **Claims match the evidence.** Drafts state magnitudes with units and the design's actual identifying assumption; nulls, failed placebos, and open flags (DEGENERATE-INFERENCE, MATCH-SENSITIVE) appear in the text, not only in logs. "Consistent with" is the ceiling for mechanism claims without direct evidence.
